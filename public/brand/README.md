# Everence brandmark

Put the approved Everence brandmark SVG from the Marketing Department here as
`everence-brandmark.svg`. Folium shows it top-left of the sidebar, about 20px tall,
with the "Folium" product name below it as plain text (never a combined lock-up).

Don't redraw, recolor or crop the artwork (Brand Guidelines p.6–11). Until the file is
here, the sidebar shows the product name only.
